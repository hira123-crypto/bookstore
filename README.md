BookStore - Online Book & Course Platform

A modern, responsive bookstore web application where users can browse free and paid books/courses, sign up, and login to access content.

##  Features

-  **Home Page** - Welcome section with featured free books carousel
-  **Course Page** - Browse all available books and courses
-  **User Authentication** - Login and Signup functionality
-  **Beautiful UI** - Modern design with Tailwind CSS
-  **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
-   **Slick Carousel** - Interactive book slider on homepage
-  **Toast Notifications** - User-friendly success/error messages

## 🛠️ Technologies Used

- **React** - Frontend framework
- **React Router DOM** - Navigation and routing
- **Tailwind CSS** - Styling and responsive design
- **React Hook Form** - Form validation and handling
- **React Slick** - Carousel/slider component
- **React Hot Toast** - Toast notifications
- **Axios** - HTTP requests (ready for backend integration)
- **Vite** - Fast build tool and dev server
